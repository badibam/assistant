Les couleurs du thème par défaut, claires et sombres, tournées autour du cercle des teintes (OKLCH) du même angle, comme le réglage « Teinte » de l'app les tourne : leur clarté et leur saturation gardées, les couleurs d'état (attention, erreur) fixes. 0 = les couleurs du thème. Une couleur hors de l'écran perd de la saturation, jamais de clarté. Les icônes des outils sur leur pastille : bleue, neutre, orange ; les couleurs des pastilles ne tournent pas, la neutre si. Un aperçu : les couleurs se changent dans DefaultTheme.kt, puis ici (DefaultColorsBenchTest vérifie qu'elles sont les mêmes).
